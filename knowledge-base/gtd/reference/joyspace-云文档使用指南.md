# Joyspace 云文档

## 链接
- 主站: [joyspace.jd.com](https://joyspace.jd.com/)

## 用途
- 存放专业领域文献笔记
- 个人笔记
- 别人发送的资料共享

## 在 GTD 中的角色
- reference 文件夹中的 `.md` 文件应包含指向 joyspace 对应文档的链接
- 每个 joyspace 文档在本地的 `.md` 文件作为索引和快捷入口
